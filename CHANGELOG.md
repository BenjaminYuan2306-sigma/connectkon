# Changelog

Notable changes are recorded here. Repository releases use semantic version labels; hosted deployment version numbers are tracked separately.

## [1.0.0] - 2026-09-09

Initial repository release. This snapshot includes the core networking workspace, the university marker and the owner analytics added during the initial product build.

### Added

- Infinite dark canvas with movable connection cards, zoom, pan and fit view.
- Editable relationship edges and resizable text nodes.
- Connection profiles, validated LinkedIn URLs and duplicate handling.
- Same-university checkbox and gold card-corner marker.
- Separate conversation records with topics, takeaways and checkable actions.
- Follow-up dates, reminders panel and next-conversation notes.
- Search, combined filters, local autosave, undo/redo and JSON backups.
- Owner-only analytics dashboard with public event collection, D1 persistence and privacy controls.
- English and Chinese READMEs, architecture and deployment documentation.
- Workspace and analytics verification suites.

### Known limitations

- Contacts remain local to the browser; no cloud contact sync or collaboration.
- Analytics uses browser estimates and requires Sites-managed owner authentication.
- Full browser UI testing and the optional WebMCP runtime check remain outstanding.
