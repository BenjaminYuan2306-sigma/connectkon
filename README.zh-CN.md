# ConnectKon

**把你的职业人脉，变成一张看得见的地图。**

ConnectKon 是一个以画布为核心的人脉管理工具。你可以整理 LinkedIn 联系人、连接彼此的关系、记录每次交流，并安排后续跟进。

**版本：1.0.0 · 首个发布版本 · 以桌面网页为主**

[在线体验](https://connectkon-network.yuanfei758.chatgpt.site/) · [English README](README.md) · [更新日志](CHANGELOG.md)

## 可以做什么？

- 在无限画布上拖动联系人卡片，缩放并查看整个人脉网络。
- 用带标签的连线记录介绍人、同事、校友等关系。
- 为每个人保存独立的对话历史、重点、待办事项和下一次想聊的话题。
- 设置跟进日期，查看已逾期、今日到期和即将到来的跟进。
- 勾选“Same university as me”，在同校联系人的卡片角落显示金色星星。
- 按姓名、公司、标签及对话内容搜索，并组合筛选条件。
- 自动保存，使用撤销/重做，以及导入、导出 JSON 备份。
- 网站所有者可登录 `/admin`，查看访客趋势、回访估算和功能使用次数。

## 使用前须知

联系人和对话保存在**当前浏览器**里，不会自动同步到其他设备。更换浏览器或清理浏览器数据前，请通过 **Settings → Export Data** 导出备份。

统计系统不收集联系人姓名、LinkedIn 链接、笔记或对话内容。访客可以在设置中关闭使用统计。统计人数按浏览器估算，不等于真实注册人数。

## 本地启动

准备 Node.js 24.x 和 pnpm 11.19.0，在项目目录运行：

```sh
pnpm install --frozen-lockfile
pnpm db:migrate:local
pnpm dev
```

打开终端显示的本地地址。检查代码可运行：

```sh
pnpm typecheck
pnpm test
pnpm build
```

完整安装说明、技术架构、后台身份配置及第一版限制，请查看 [English README](README.md)。

## 第一版范围

这是一个可使用的初始版本，核心是画布、关系记录和后续跟进。目前不包含联系人云同步、多人协作、LinkedIn 抓取或自动 AI 总结。自动化验证覆盖数据和接口逻辑，完整浏览器交互测试尚未完成。

欢迎通过仓库 Issues 提交问题与建议。首版尚未选择项目级开源许可证。
